# Research report

1. Lead with the decision-relevant conclusion and the conditions under which it
   would change.
2. Structure the body as thesis, evidence, counterevidence, risks, scenarios,
   and open questions.
3. Cite exact URLs next to externally verifiable claims. Prefer SEC and FRED
   primary sources over summaries.
4. Label calculations and model inferences; link them to reproducible artifact
   paths where applicable.
5. Include source coverage, data cut-off, material gaps, and uncertainty.
6. Keep internal agent activity, tool logs, and raw payloads out of the report.

If evidence is insufficient, narrow the conclusion instead of filling gaps with
plausible language.
